Программа на Python для расчёта площади прямоугольника с проверкой корректности введённых данных.

## Описание

Программа запрашивает у пользователя длину и ширину прямоугольника, проверяет, что введённые числа положительные (больше нуля), и вычисляет площадь.

## Возможности

- Ввод длины и ширины прямоугольника
- Проверка на отрицательные числа и ноль
- Повторный запрос числа при некорректном вводе
- Расчёт и вывод площади

## Как запустить

1. Убедиться, что установлен Python 3
2. Запустить команду в терминале:

python3 Area.py
